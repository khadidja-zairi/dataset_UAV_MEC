# UAV-MEC Raw Dataset

This repository contains the initial raw dataset used in the study:

"Deep Learning for Optimizing Virtual Resources Allocation in MEC-based UAV Environments"

# Content
- UAV mobility and position data
- MEC server resource information
- Task offloading requests

# Important Note
This repository contains only the raw dataset before preprocessing.

The processed and filtered dataset used for experiments
will be made available after paper acceptance.

# Usage
This dataset is provided for research and academic purposes only.
